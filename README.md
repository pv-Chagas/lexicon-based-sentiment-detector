# Lexicon-Based Sentiment Analysis

**Tema 2: Detector de Sentimentos Baseado em Léxico**

Estudo de caso em Python: classificar textos como positivos, negativos ou neutros. Calcular percentuais de cada classe.
Considerar intensificadores como: muito bom, extremamente ruim.
